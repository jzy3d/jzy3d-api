jzy3d-tools-jply
================

Reads PLY files, used by `org.jzy3d.io.ply.Ply` in `jzy3d-core`.

Source code of [jPLY](https://github.com/smurn/jPLY) 0.2.1 as forked in [jzy3d/jPLY](https://github.com/jzy3d/jPLY) (commit `8bc38f3`), which is not available on Maven Central (only 0.2.0 is). Package `org.smurn.jply` is unchanged.
